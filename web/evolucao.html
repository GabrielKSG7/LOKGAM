      Como isto é medido

      De onde vem
      Um robô coleta o catálogo uma vez por dia e grava só o que mudou: entradas que chegaram, saíram ou trocaram de endereço. Outro confere se cada versão jogável responde e grava só as trocas de situação. A lista de cada dia é refeita a partir desses registros.
      Um port
      Entradas que apontam para o mesmo endereço jogável contam como um port. O jogo de cada port vem do nome, sem o que a lista põe entre parênteses.
      Console de origem
      Vem das fichas curadas e de uma tabela de referência mantida à mão. O que não está em nenhuma das duas aparece como "Não classificado": é a maior parte, e muita coisa ali é jogo de PC.
      "Chegaram"
      Só conta como novo o port que apareceu depois da primeira coleta, de 11/11/2026. Os que já estavam lá têm data desconhecida.
      Quebrado
      Versão que respondeu com erro ou não respondeu na última conferência. Não diz se o jogo funciona quando a página abre.
      Os números
      Tabelas em data/gold, geradas por modelos dbt sobre DuckDB, com testes que conferem as contas contra o que os robôs registraram.

      Jogos, nomes e marcas pertencem aos seus donos. Esta página mostra domínios como texto, sem link para os ports.
